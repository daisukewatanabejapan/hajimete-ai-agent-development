# AGENTS.md

## このプロジェクトについて

このリポジトリはGoで作られた〇〇です。

## 主な場所

- `cmd/`：実行プログラム
- `internal/`：内部パッケージ
- `pkg/`：外部から利用するパッケージ
- `go.mod`：モジュールと依存関係

存在しない項目は削除してください。

## お願い

- 依頼に関係する部分だけを変更してください。
- パッケージの責務を大きく変える場合は、先に理由を説明してください。
- エラーを無視せず、呼び出し側が判断できる形で返してください。
- 不具合修正では、テーブル駆動テストを含む再発防止テストを検討してください。
- `go.mod` と `go.sum` は依存関係を変えたときだけ更新してください。
- APIキーやパスワードをコードへ書かないでください。

## 確認コマンド

    gofmt -l .
    go vet ./...
    go test ./...

`gofmt -l .` がファイル名を表示した場合は、変更したGoファイルを整形してください。

## 完了時の報告

- 変更内容
- 実行した確認コマンドと結果
- 実行できなかった確認と理由
