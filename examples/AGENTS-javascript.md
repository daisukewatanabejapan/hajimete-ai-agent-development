# AGENTS.md

## このプロジェクトについて

このリポジトリはJavaScriptで作られた〇〇です。

## 主な場所

- `src/`：プログラム本体
- `test/` または `tests/`：テスト
- `public/`：静的ファイル
- `package.json`：スクリプトと依存関係

実際の構成に合わせて書き換えてください。

## お願い

- 依頼に関係する部分だけを変更してください。
- プロジェクトが採用しているES ModulesまたはCommonJSの方式を維持してください。
- ブラウザとNode.jsのどちらで動くコードかを確認してください。
- 不具合修正では、できるだけ再発防止テストを追加してください。
- `package-lock.json` は依存関係を変えたときだけ更新してください。
- 新しいパッケージを追加するときは理由を説明してください。
- APIキーやパスワードをコードへ書かないでください。

## 確認コマンド

`package.json` に存在するコマンドだけを残してください。

    npm ci
    npm test
    npm run lint
    npm run build

## 完了時の報告

- 変更内容
- 実行した確認コマンドと結果
- 対象ランタイム（ブラウザまたはNode.js）
- 実行できなかった確認と理由
