## このプロジェクトについて

## 主な場所

- `src/`：プログラム本体

## お願い

- 依頼に関係する部分だけを変更してください。
- `package-lock.json` は依存関係を変えたときだけ更新してください。
- 不具合修正では、できるだけ再発を防ぐテストを追加してください。
- 新しいパッケージを追加するときは理由を説明してください。
- APIキーやパスワードをコードへ書かないでください。

## 確認コマンド

プロジェクトで使っているコマンドだけを残してください。

    npm test
    npm run lint

## 完了時の報告

- 変更内容
