# AGENTS.md

## このプロジェクトについて

このリポジトリはRustで作られた〇〇です。

## 主な場所

- `src/`：プログラム本体
- `tests/`：結合テスト
- `examples/`：利用例
- `Cargo.toml`：パッケージと依存関係

実際の構成に合わせて書き換えてください。

## お願い

- 依頼に関係する部分だけを変更してください。
- `unsafe` を追加するときは、必要な理由と安全条件を説明してください。
- 公開APIを変更するときは、利用者への影響を説明してください。
- 不具合修正では、できるだけ再発防止テストを追加してください。
- `Cargo.lock` はプロジェクトの既存方針に従って扱ってください。
- APIキーやパスワードをコードへ書かないでください。

## 確認コマンド

    cargo fmt --check
    cargo clippy --all-targets --all-features -- -D warnings
    cargo test --all-features

## 完了時の報告

- 変更内容
- 実行した確認コマンドと結果
- `unsafe` や公開APIへの影響の有無
- 実行できなかった確認と理由
