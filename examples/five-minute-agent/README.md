# 5分で動くAIエージェント

[日本語](./README.md) | [English](./README.en.md)

問い合わせを分類し、返信案を作り、人の確認待ちにする小さなサンプルです。

## 1. 必要なもの

- Python 3.9以上
- ターミナル

APIキー、外部ライブラリ、ネットワーク接続は不要です。

## 2. 動かす

リポジトリのルートから実行します。

```bash
cd examples/five-minute-agent
python3 agent.py
```

別の問い合わせも試せます。

```bash
python3 agent.py --text "保存ボタンを押しても反応しません"
python3 agent.py --text "パスワードの変更方法を教えてください"
```

## 3. テストする

```bash
python3 -m unittest -v
```

## 出力例

```json
{
  "category": "bug",
  "summary": "保存ボタンを押しても反応しません",
  "reply_draft": "ご報告ありがとうございます。発生した環境と再現手順を教えてください。",
  "needs_human_review": true,
  "trace": [
    "input_validated",
    "request_classified",
    "reply_drafted",
    "output_validated"
  ]
}
```

## 何を学べるか

```text
入力 → 入力検証 → 分類 → 返信案 → 出力検証 → 人の確認
```

- 空や長すぎる入力を拒否する
- 出力を3種類の分類に限定する
- 処理内容を `trace` に残す
- 返信を自動送信せず、人の確認を必須にする
- 正常系と失敗系をテストする

## これは生成AIですか？

この最初のサンプルは、分類と返信案を決定的なローカル規則で作ります。生成AIモデルは使いません。

理由は、API設定より先に「モデルの周囲に必要な安全な制御」を理解し、誰でも同じ結果でテストできるようにするためです。実運用では `classify()` と `draft_reply()` をモデル呼び出しへ置き換えられますが、入力検証、出力検証、人の承認、テストは残します。
