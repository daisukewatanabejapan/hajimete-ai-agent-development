# AGENTS.md

## プロジェクト

このリポジトリは〇〇チームが管理する〇〇です。

## 担当領域

- `src/`：アプリケーションチーム
- `infra/`：基盤チーム。変更前に確認が必要
- `docs/`：全員が変更可能

## 作業ルール

- Issueの完了条件を変更せず、必要最小限の差分にしてください。
- 公開API、DBスキーマ、依存関係の変更は事前に提案してください。
- 不具合修正には再発防止テストを追加してください。
- 関係のない整形やリファクタリングを混ぜないでください。

## 確認

    ここにlint、test、buildコマンドを書く

## Pull Request

- 変更理由、利用者への影響、確認結果を書く
- 実行できなかった確認を隠さない
- 人のレビューが終わるまでマージしない
