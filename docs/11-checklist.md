# AIエージェント開発チェックリスト

すべてにチェックが付く必要はありません。該当しない項目には理由を残します。

## 目的と範囲

- [ ] 目的を1文で説明できる
- [ ] AIに任せることと任せないことが分かれている
- [ ] 完了条件が観察またはテストできる
- [ ] 変更してよい範囲が明確

## 入力と出力

- [ ] 必要な入力と不足時の動作が決まっている
- [ ] 外部入力の長さ、形式、必須項目を検証する
- [ ] 出力形式と許可値が決まっている
- [ ] 根拠がない場合は推測しない

## 道具と権限

- [ ] 道具は必要最小限の権限だけを持つ
- [ ] 読み取りと書き込みが分かれている
- [ ] 送信、削除、購入、公開には人の承認がある
- [ ] 再試行回数と重複防止が決まっている

## セキュリティとプライバシー

- [ ] 秘密情報をプロンプト、コード、ログへ書かない
- [ ] 個人情報は必要な範囲だけ扱う
- [ ] ツールやWebの出力を命令ではなくデータとして扱う
- [ ] 外部へ送るデータを確認する

## 品質

- [ ] 正常系、境界値、失敗系をテストする
- [ ] 過去の失敗入力を回帰テストにしている
- [ ] lint、テスト、ビルドの実コマンドがある
- [ ] AIの完了報告ではなく差分を確認する

## 運用

- [ ] 実行、使用ツール、結果、承認、エラーを記録する
- [ ] 失敗時に安全に停止または人へ引き継ぐ
- [ ] コスト、時間、成功率を確認できる
- [ ] ルールとテストの更新担当が決まっている

## 公開前

- [ ] READMEと利用例がある
- [ ] 秘密情報と個人情報を再確認した
- [ ] ライセンスと依存関係のライセンスを確認した
- [ ] 人が最終レビューした
