# PLANS.md

Use this simple plan template before starting a larger change.

> `PLANS.md` is not a required Codex configuration file. It is a convention used by this guide.

You do not need a plan for a small typo fix. Use one when changing several files or making design decisions.

---

# Task name

## Goal

Describe what you want to achieve in one to three sentences.

## Non-goals

List what is not included in this task.

## Steps

- [ ] Review the current state
- [ ] Implement the required change
- [ ] Run tests or other checks
- [ ] Review the final diff

## Done when

- What must be observable when the task is complete?
- Which tests or checks must pass?

## Cautions

List behavior that must not break and actions that require approval.

## Work log

Record discoveries and explain why the plan changed.
